# Awesome DESIGN.md

Each brand has a `design-md/<brand>/DESIGN.md` describing its design system (palette, typography, spacing, components, do/don't) and a README.

Usage:
1. List brands: `ls .claude/skills/awesome-design-md/design-md`
2. Read the matching `design-md/<brand>/DESIGN.md`.
3. Apply its tokens and rules when generating UI; adapt for RTL/Persian when the project requires it.
